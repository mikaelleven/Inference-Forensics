# Developer Guide

## Purpose

Small, deterministic benchmark harness for comparing coding models and coding-agent harnesses..

## Development targets

- Platform(s): cross-platform
- Primary technology: Python
- Primary language: python
- Language/toolchain version: 3.11
- Secondary/support technology: Python
- Secondary language: python
- Blueprint: python.cli

## Local development setup

Run the generated setup script appropriate for the current platform.

## Development conventions

- Use deterministic support scripts for repeatable setup and validation.
- Use the resolved secondary technology for non-trivial support automation.
- Do not introduce another scripting runtime unless it materially simplifies the project.
